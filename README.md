## 🏆 Featured Write-Up: Bandit Level 13

### 🎯 Objective
Retrieve the password for `bandit14` using SSH private key authentication.

### 🛠️ Tools Used
```bash
ssh -i sshkey.private bandit14@localhost
```

### 📋 Steps to Reproduce
1. Login as bandit13:  
   ```bash
   ssh bandit13@bandit.labs.overthewire.org -p 2220
   ```
2. Find the private key:  
   ```bash
   ls -la
   ```
   Output: `sshkey.private`
3. Use the key to login as bandit14:  
   ```bash
   ssh -i sshkey.private bandit14@localhost
   ```

### 📸 Screenshot
*(Take a screenshot and upload it to this repo)*

### 💡 Lessons Learned
- SSH keys are more secure than traditional passwords
- The `-i` flag specifies the private key file
- This is the industry standard for server management
