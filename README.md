## 🛠️ Featured Security Projects

### 🐍 [python-cyber-tools](https://github.com/jaiek2k25/python-cyber-tools)
Production-grade security scripts built from scratch using raw Python standard libraries.
* **Multithreaded TCP Port Scanner:** High-speed socket scanner featuring concurrent thread pools, banner grabbing, and `argparse` CLI interfaces.
* **Web Header Security Inspector:** Automated response auditor checking web targets for missing security headers (CSP, HSTS, X-Frame-Options).

### 🔐 [overthewire-writeups](https://github.com/jaiek2k25/overthewire-writeups)
Structured methodology logs detailing Linux CLI security, permission boundaries, and privilege escalation.

### 💀 [htb-writeups](https://github.com/jaiek2k25/htb-writeups)
Hands-on machine exploitation write-ups documenting service enumeration and vulnerability research.
* **Starting Point Track:** Detailed notes on Tier 0 & Tier 1 machines (Nmap service fingerprinting, SMB, and FTP exploitation).
