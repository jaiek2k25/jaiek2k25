## 🛠️ Featured Project: Python Port Scanner

*Built from scratch using raw sockets—demonstrates understanding of TCP/IP.*

```python
# Snippet from my custom scanner
import socket
target = "127.0.0.1"
for port in range(1, 1024):
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.settimeout(0.5)
    result = sock.connect_ex((target, port))
    if result == 0:
        print(f"Port {port}: Open")
    sock.close()
```
