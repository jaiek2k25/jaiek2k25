## 🏆 Featured Write-Up: Bandit Level 13

### 🎯 Objective
Retrieve the password for the `bandit14` user using SSH private key authentication.

### 🛠️ Tools Used
- `ssh` (with the `-i` flag for private key authentication)

### 📋 Steps to Reproduce
1.  Logged in as `bandit13` using the password obtained from Level 12.
2.  Listed the directory contents: `ls -la`
3.  Found the private key file: `sshkey.private`
4.  Used the key to log in as `bandit14`:
    ```bash
    ssh -i sshkey.private bandit14@localhost
    ```

### 📸 Proof (Screenshot)
![Bandit Level 13 Solution](link-to-your-screenshot.png)

### 💡 Lessons Learned
This was my first real-world application of SSH key-based authentication. I learned that:
- Private keys are significantly more secure than traditional passwords.
- The `-i` flag is used to specify the private key file for authentication.
- This method is the industry standard for securely managing servers and automating tasks.
